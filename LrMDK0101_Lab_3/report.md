# Лабораторная работа № 3

## Тема

Учёт продаж, формирование отчёта и сохранение чека

## Цель работы

Создать консольное приложение на C#, предназначенное для хранения данных о товарах и продажах, формирования отчёта за выбранный период, а также создания и сохранения чека.

## Используемые средства

- язык программирования C#;
- среда разработки Visual Studio;
- платформа .NET.

## Описание программы

Программа состоит из классов, каждый из которых отвечает за отдельную часть работы с данными.

- `ProductGroup` — перечисление товарных групп `Gruz` и `NotGruz`.
- `Nomenclature` — класс для хранения названий товаров по группам и поиска группы товара.
- `SaleItem` — класс, описывающий одну продажу: дату, название товара, количество и цену.
- `SaleHistory` — класс для хранения списка продаж.
- `ReportRow` — структура с данными для строки отчёта: названием товара, количеством проданных единиц и стоимостью.
- `ProfitByPeriodReport` — класс для хранения строк отчёта.
- `Accountant` — класс с методом `MakeReport`, который формирует отчёт по продажам за указанный период.
- `Receipt` — класс для формирования чека, его вывода в консоль и сохранения в текстовый файл.

## Ход работы

1. Создан проект консольного приложения на C# в Visual Studio.
2. Добавлены классы для описания товарных групп, номенклатуры, отдельных продаж и истории продаж.
3. Реализован сбор продаж за заданный период и группировка результатов по названию товара.
4. Добавлен класс `Receipt` для формирования текста чека.
5. В чеке предусмотрены название товара, количество, цена за единицу, стоимость позиции и итоговая сумма.
6. Добавлен вывод чека в консоль и сохранение его в текстовый файл.
7. В методе `Main` созданы примеры продаж и вызваны операции формирования, вывода и сохранения чека.

## Результат работы

Программа хранит сведения о продажах, позволяет сформировать отчёт за выбранный период, вывести чек в консоль и сохранить чек в текстовый файл.

## Вывод

В ходе лабораторной работы были закреплены навыки разработки консольных приложений на C#, создания классов и объектов, работы со списками и словарями, обработки данных и сохранения текстовой информации в файл. Также была отработана организация программы, при которой разные классы отвечают за хранение данных, расчёты и формирование результатов.
